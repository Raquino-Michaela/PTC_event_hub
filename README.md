# PTC Event Hub

## Project Overview
PTC Event Hub is a web-based campus event finder and ticket management system designed for students, administrators, and event organizers at Pateros Technological College. It allows students to discover upcoming campus activities, register for events, and manage their tickets in real time.

## Features
Event Discovery – Browse upcoming campus events and activities.
Event Registration – Register for events online.
Ticket Management – View and manage registered event tickets.
Event Management – Allow organizers to create and manage events.
Event Updates – Receive information about upcoming events.
